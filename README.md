# Playground

This repository is a personal development playground used for experimenting with ideas, tools, frameworks, and concepts.

Each branch represents a separate experiment or exploration.

## Purpose

- Try out new technologies and workflows
- Prototype ideas before extracting them into real projects
- Experiment freely without worrying about structure or stability
- Keep a reference of things I’ve learned or tested

## How it’s organized

- **Main branch**: Minimal base (mostly empty)
- **Feature branches**: Each branch focuses on one topic or experiment

## Notes

- Code may be incomplete or intentionally rough
- Branches may be rebased, rewritten, or deleted
- This repo is primarily for learning and experimentation

Feel free to explore.
